# Module: Dart library (`lib/`)

## 1) Purpose and why it exists

The `lib/` tree is the **Flutter/Dart surface** of the Finvu Account Aggregator (AA) authentication flow: complete authentication **without manual OTP entry** where the backend/native stack supports it, by delegating to **native** `FinvuAuthentication*` implementations via **Pigeon**.

It exists so host apps get:

- A **stable Dart API** (`IFinvuHost`, `IFinvuWebViewWrapper`, `IFinvuNativeWrapper`) instead of calling platform channels by hand.
- Two integration styles: **embedded WebView** (JS bridge) and **fully native UI** (calls from Flutter widgets).

## 2) Versioning

- **Source of truth:** `pubspec.yaml` → `version:` (currently `1.0.0`).
- **Lockstep:** When you bump the plugin version, also align:
  - `ios/finvu_auth_sdk_flutter.podspec` → `s.version`
  - `android/build.gradle` → `version` (library module)
  - `CHANGELOG.md`

Semantic versioning: **MAJOR** for breaking Dart/Pigeon API changes; **MINOR** for additive APIs; **PATCH** for fixes.

## 3) Setup and installation (consumer app)

In the **host app** `pubspec.yaml`:

```yaml
dependencies:
  finvu_auth_sdk_flutter: ^1.0.0   # or path/git as appropriate
```

Then `flutter pub get`.

**Platform prerequisites** (not in `lib/` but required for the plugin to run):

- **Android:** Maven repository for `com.finvu.android:finvuauthenticationsdk` (GitHub Packages — see [release-and-credentials.md](./release-and-credentials.md)).
- **iOS:** `FinvuAuthenticationSDK` via CocoaPods (git tag from `Cookiejar-technologies/finvu-auth-sdk-ios` — see [module-ios.md](./module-ios.md)).

## 4) Architecture and folder structure

```
lib/
├── finvu_auth_sdk.dart          # Barrel exports (public entry)
├── utils/
│   └── finvu_auth_response_utils.dart   # Helpers for Pigeon enums → strings
└── src/
    ├── models.dart              # Public domain models (Environment, FinvuAuthResult, …)
    ├── factory.dart             # FinvuAuthSdk — resolves default implementations
    ├── api/                     # Abstract interfaces (testability / swapping impls)
    │   ├── finvu_host.dart
    │   ├── finvu_webview_wrapper.dart
    │   └── finvu_native_wrapper.dart
    ├── impl/                    # Default implementations
    │   ├── finvu_host_impl.dart         # Pigeon FinvuHostApi
    │   ├── finvu_webview_wrapper_impl.dart  # JS channel → host
    │   ├── finvu_native_wrapper_impl.dart   # Thin delegate to host
    │   └── mapper.dart                # Pigeon ↔ public models
    └── generated/
        └── native_finvu_auth_wrapper.g.dart   # Generated by Pigeon — do not edit
```

### How each piece is used

| Piece | Role |
|-------|------|
| **`IFinvuHost`** | Canonical async API: `setEnvironment`, `initAuth`, `startAuth`, `verifyOtp`, `cleanupAll`. |
| **`FinvuHostImpl`** | Binds to generated `FinvuHostApi` (Pigeon) which calls Android/iOS native code. |
| **`IFinvuWebViewWrapper`** | Registers a JavaScript channel (`finvu_authentication_bridge`) and maps JSON messages to `IFinvuHost` methods; executes callback JS on the WebView. |
| **`IFinvuNativeWrapper`** | Same auth calls as host, for Flutter screens that do not use WebView (thin wrapper). |
| **`FinvuAuthSdk` factory** | Single place to obtain defaults: `FinvuAuthSdk.host()`, `.webViewBridge()`, `.nativeWrapper()`. |

### Dependencies (`pubspec.yaml`)

- **`pigeon`**: Code generation only (dev-time); generated files are committed.
- **`webview_flutter`**: Required for `IFinvuWebViewWrapper` implementation.

## 5) Release process

See [release-and-credentials.md](./release-and-credentials.md). Dart package is published with **`flutter pub publish`** (or `dart pub publish`) from the package root after version bump and validation.

## 6) Making changes (developer workflow)

1. **API change:** Edit `pigeons/native_finvu_auth_wrapper.dart`, then run Pigeon codegen (see [module-pigeon.md](./module-pigeon.md)).
2. **Behavior change in WebView bridge:** Edit `lib/src/impl/finvu_webview_wrapper_impl.dart` — keep channel name `finvu_authentication_bridge` aligned with the web app.
3. **New public type:** Add to `lib/src/models.dart`, export from `finvu_auth_sdk.dart` if needed, update mappers.

Run analysis: `dart analyze` / `flutter analyze` from package root.
